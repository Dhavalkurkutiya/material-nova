## 🎨 Theme Variants

Enjoy a carefully curated set of 6 beautiful, distraction-free variants designed for long coding sessions:

*   🌌 **Material Nova** — The signature blue-green dark theme.
*   🖤 **Material Nova Darker** — A pure, deep black theme for OLED screens.
*   🔮 **Material Nova Palenight** — A gorgeous purple-blue night sky aesthetic.
*   🌊 **Material Nova Ocean** — A calming, deep navy ocean breeze layout.
*   🌲 **Material Nova Deepforest** — A rich, organic dark forest green experience.
*   ☀️ **Material Nova Lighter** — A crisp, clean light variant for bright environments.

*Every dark variant also includes a **High Contrast** edition to enhance readability and reduce eye strain!*

---

## ✨ Features & What's Included

*   🚀 **Semantic Highlighting:** Custom token colors optimized specifically for modern web languages (`React`, `Next.js`, `TypeScript`, `Node.js`, `C#`, `Python`, etc.).
*   🎨 **Accents Synchronized:** Works seamlessly with VS Code's editor accents and custom configurations.
*   🕶️ **Distraction-Free:** Carefully selected contrast levels that highlight what's important while keeping UI noise minimal.
*   📦 **Lightweight & Fast:** Pure JSON configurations with zero runtime performance impact on your editor.

---

## 🚀 Quick Setup & Installation

1. Open **VS Code**.
2. Open Extensions view (`Ctrl+Shift+X` or `Cmd+Shift+X`).
3. Search for **`Material Nova`**.
4. Click **Install**.
5. Press `Ctrl+K` then `Ctrl+T` (or `Cmd+K` then `Cmd+T`) and select your favorite variant from the list!
